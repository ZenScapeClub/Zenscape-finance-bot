# Египет + Петербург · Telegram-бот и Mini App

Пошаговый план двухнедельного отпуска (17–31 октября 2026, двое, день рождения 25 октября):
Петербург → Хургада → Каир → дайв-бот / пустыня на день рождения → Эль-Гуна → Луксор → домой.

Один процесс `main.py` запускает:

* **Telegram-бота** (long polling) — план по дням, билеты, виза, транспорт, отели, рестораны,
  день рождения, бюджет, чек-лист с галочками, утренние/вечерние напоминания;
* **HTTP-сервер** на порту `PORT` (по умолчанию 80) — раздаёт Mini App (`webapp/index.html`)
  с уже встроенными данными и JSON-API `/api/trip`.

Все данные поездки — в одном файле `data/trip.json`. Бот и Mini App читают его одинаково.

## Структура

```
egypt-spb-trip/
├── main.py            # бот + http-сервер
├── data/trip.json     # весь контент: дни, билеты, виза, отели, рестораны, чек-лист…
├── webapp/index.html  # Mini App (одна страница, без сборки)
├── build_static.py    # собирает dist/index.html со встроенными данными для статического хостинга
├── requirements.txt
├── amvera.yaml        # деплой на Amvera (persistenceMount /data — для чек-листа и подписок)
└── Procfile
```

## Запуск локально

```bash
python -m venv venv && . venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=123:abc
export PORT=8080                 # http://localhost:8080 — Mini App в браузере
python main.py
```

## Переменные окружения

| Переменная | Что делает |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather (обязательно) |
| `WEBAPP_URL` | https-адрес Mini App. На Amvera — домен проекта, например `https://egypt-trip-<логин>.amvera.io/`. Без него бот работает, но кнопки «Открыть приложение» не будет |
| `ALLOWED_USERS` | id пользователей через запятую (свой и супруги). Пусто — доступ всем |
| `ADMIN_USERS` | кто может делать `/reload` (по умолчанию = `ALLOWED_USERS`) |
| `PORT` | порт http-сервера, на Amvera оставить 80 |
| `STATE_DIR` | где хранить чек-лист и подписки; на Amvera автоматически `/data` |

## Бот

Используем существующего бота **@serbia_otpusk_bot** (тот же, что был для Сербии) — в нём просто меняется
контент и Mini App. Токен хранится только в переменных окружения (см. `.env.example`), в репозиторий не кладём.
Если токен «засветился» в переписке — в @BotFather → `/revoke` выдаст новый, старый перестанет работать.

Важно: у Telegram один токен = один процесс long polling. Перед запуском нового кода остановите старый
деплой сербского бота (иначе оба будут получать ошибку `Conflict: terminated by other getUpdates request`).

## Деплой на Amvera (как у финансового бота)

1. Создать проект **Python**, репозиторий — эта папка (удобнее вынести её в отдельный репозиторий
   или указать в настройках Amvera путь к `amvera.yaml`).
2. В «Переменные» добавить `TELEGRAM_BOT_TOKEN`, `ALLOWED_USERS`, `WEBAPP_URL`.
3. В «Домены» включить бесплатный домен `*.amvera.io` — он и будет `WEBAPP_URL` (Telegram требует https).
4. Пересобрать. После старта бот сам выставит команды и кнопку меню «План», открывающую Mini App.

Mini App можно раздавать и с любого статического хостинга: `python build_static.py` → `dist/index.html`
(например, GitHub Pages), тогда `WEBAPP_URL` указывает туда.

## Команды бота

`/start` меню · `/app` открыть Mini App · `/today` план на сегодня · `/tomorrow` · `/day N` ·
`/plan` все дни · `/flights` · `/visa` · `/car` транспорт и аренда · `/hotels` · `/food` ·
`/birthday` · `/budget` · `/checklist` · `/info` полезное · `/remind on|off` · `/reload` (админ).

Напоминания: план дня в 08:00 и превью завтрашнего дня в 21:00 по времени Каира в дни поездки,
дедлайны чек-листа в 10:00 по Петербургу за 3 дня до срока. `/start` включает подписку.

## Как править план

Открыть `data/trip.json`, поправить нужный день/раздел, задеплоить (или `/reload` в боте без перезапуска).
Каждый блок дня: `time`, `type` (`fly` `move` `see` `meal` `book` `rest` `dive` `party` `hotel` `bus` `boat` `walk` `car`),
`title`, `text`, `how` (как добраться), `price`, `link`.
